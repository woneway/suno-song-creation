# 曲风 Profile 库

> 2026-07-04 建立(专项调研:通用/曲风知识分层 + 爵士词法)。
> **定位:profile 是各曲风创作参数(曲式/词法/弧线/hook/收尾)的唯一默认值来源**——SKILL.md 只提供体裁无关的方法论与平台机制,不含这些参数的"通用默认"。与其他参考文件冲突时,profile 胜。
> 词法字段刻意写得最细——句长/押韵/语气/姿态/意象是最容易被错误通用化的维度。

## 使用协议

1. **写词前**:载入目标曲风 profile → 曲式/词法/弧线/hook 机制以 profile 为准(它是唯一默认值来源)。
1b. **缺字段协议**:profile 缺某字段时,按字段说明现场调研补齐该字段并回写本文件;禁止从其他曲风 profile 或本仓案例借值。**轻量路径**:缺的若是词法子字段,可先按「music-theory/lyrics-advanced 通用规则 + 本 profile 身份要素」推导补齐,标注「推导待验证」回写,下一首同曲风歌验证后转正;身份要素/曲式级字段缺失仍需正式调研。
2. **迭代时**:用户反馈「不像这个曲风」→ 先对照 `身份要素` 逐条检查哪条丢了 → 再查 `常见跑偏` 是否命中 → 最后才改词面。禁止只改风格串。
3. **无对应 profile 的曲风**:按本文件的字段结构现场调研补一份,入库复用。
4. **子曲风差异大时分述**(如爵士的 swing 与 ballad、摇滚的 anthem 与诗性路线)。
5. **可唱性基线(2026-07-06 起)**:载入 profile 的同时必载 **references/singability.md**(基线层——核心可跟段/节拍锚/大众音域/一字一音/低词负荷)。低跟唱潜力曲风(其第三节潜力表)在选型期告知用户上限并确认;基线与 profile 词法冲突时暴露给用户取舍,禁止静默牺牲任何一方。

## 字段说明

每份 profile 含:**身份要素**(3-5 条降序,"少了它就不像";生成与迭代的资源优先保它)· **曲式**(默认结构+器乐段留位)· **律动/BPM** · **和声** · **配器** · **人声** · **词法**(句长/押韵/语气姿态/意象,分开写,它们独立变化)· **弧线与 hook** · **常见跑偏**(=最易滑向的邻近曲风+AI 生成典型病)· **Suno 要点**(风格串锚词/Exclude 方向/平台已知问题)。

## 1. 民谣(campus/城市)

- **身份**:白描叙事、口语真实感、木吉他为心脏、私人化细节。
- **曲式**:V-C 或 V-PC-C,Bridge 可省;分节歌(同旋律换词推进)是合法母体。60–90 BPM,straight。
- **和声**:自然大小调三和弦+挂留,进行简单(卡农系/1645 系)。**配器**:指弹木吉他、钢琴/口琴/大提琴点缀、鼓轻或无。**人声**:本嗓近麦叙事口吻,禁炫技。
- **词法**:句长 8–12 字、邻行接近但不必严格对称;跳押(二四句)或宽辙一韵到底;语气=对朋友讲故事;姿态=第一人称回忆;细节=白描,地名物件越具体越好。**避开民谣陈词区**(南方/姑娘/流浪/夜——语料研究显示高频词高度趋同)。
- **弧线与 hook**:平缓或克制反转;分节歌用"钩子变奏"(同位置词义递进)。**做档 3 合唱时**弧线取**密度累积爬升**(独唱→加合唱→全体齐唱),靠人数与密度爬升、非 belting 音量爬升(民谣禁炫技的合唱能量形态)。
- **跑偏**:民谣腔高频词堆砌;情绪直说不给细节;城市民谣写成校园怀旧套皮。**档 3 合唱的普遍化人称会加剧套皮**(为集体可代入而写空)——普遍化 ≠ 套用怀旧/励志套语,真实细节仍是命(唐恬式:普遍化人称 + 具体细节论据)。
- **Suno 要点**:`folk ballad, fingerstyle acoustic guitar, natural loose timing, intimate storyteller voice`;防赶拍靠低 BPM+loose timing。本仓案例:《归燕》《正午的月亮》(见 proven-templates)。

## 2. 主流流行 ballad

- **身份**:大副歌、题眼句、情绪爬升、普遍化人称("我懂你"式)。
- **曲式**:V-PC-C ×2 + Bridge + Final Chorus(可升 key);58–75 BPM。
- **和声**:大小调+副属和弦,4536251/卡农进行,FC 前蓄力。**配器**:钢琴/吉他开场→鼓进→弦乐铺满→FC 全奏。**人声**:主流唱商,副歌 belting 合法。
- **词法**:主歌 8–11 字,副歌 7–9 字**更整齐**(此曲风"副歌更短更齐"成立);题眼句全曲 4–6 次、位置固定、逐字重复(口径同 music-theory 1.5);宽辙一韵到底或主副两韵;主歌全部细节=论据,**副歌脱离具体情节**供代入(唐恬式)。
- **弧线与 hook**:爬升型,顶点 Final Chorus(最高点 70–85% 处、第一遍副歌不给满、大副歌前先收再放——这套动态戏剧学属于本曲风)。
- **跑偏**:副歌还在讲具体情节;全篇形容词抒情;凑韵油腻。
- **Suno 要点**:`emotional mandarin ballad, soaring chorus, lush strings`;克制型变体见民谣/本仓模板 A。

## 3. uptempo 流行

- **身份**:hook 密度、节奏词、50 秒内进副歌、可跟唱。
- **曲式**:短 intro(可用副歌旋律预告)、V-PC-C 紧凑、全曲 3 分半内;100–120 BPM。
- **和声**:四和弦循环,明亮。**配器**:punchy 鼓、亮合成器/电吉他。**人声**:节奏咬字清晰,副歌叠和声。
- **词法**:副歌 4–7 字短句、逐字重复极密;主歌 6–10 字紧凑(比副歌长、比 ballad 短);**音节镜像对称优先于语义**(Max Martin melodic math:全曲仅 3–4 个旋律部件);押韵中高密度、宽辙,hook 行可双押点缀、verse 跳押即可;重拍放开口元音;语气直给,祈使句/口号/身体动作词;意象=场景快照/身体动作域,少铺陈深挖(信息密度让位于 groove);现在时态。(句长/押韵/意象三项为 2026-07 演练回写,推导自 music-theory 1.3/1.5+本节身份要素,待实测验证)
- **弧线与 hook**:爬升+循环混合,hook 前置。
- **跑偏**:词太文太满;长句挤破 groove;信息过载淹没 hook。
- **Suno 要点**:`mandarin pop, punchy drums, catchy hooks, 100-118 BPM`。

## 4. 摇滚

- **身份**:riff 即第二 hook、力量与真实态度、词可喊。
- **曲式**:V-C ×2 + **guitar solo**(常取代 Bridge——"Bridge 最深最静"在此不成立,能量不降反升)+ C;100–140 BPM。
- **和声**:强力和弦、小调/多利亚、蓝调音。**配器**:双电吉他+贝斯+鼓,失真;**词必须给 riff 和 solo 留空**。**人声**:胸声,嘶吼与 belting 合法(Exclude 别再排除)。
- **词法**:两条路线——①anthem:副歌按千人合唱设计,元音重、音节少、词义有力量,句长 4–8 字,气势>韵;②诗性(万青/腰系):主歌散文化长句、意象允许两步领悟、社会切片实景。语气=宣言/对抗/自嘲。
- **弧线与 hook**:爬升型,solo 常是能量顶点或第二顶点;hook=可喊的副歌短句 + riff(器乐 hook 与人声 hook 双轨)。
- **跑偏**:写成"流行+失真吉他"(句式仍是 ballad 对称句);假愤怒口号化;词太满没给乐器空间。
- **Suno 要点**:`mandarin rock, overdriven guitars, driving drums, raw powerful vocals`。

## 5. R&B / soul

- **身份**:pocket/groove 感、转音空间、开元音、亲密对话。
- **曲式**:V-PC-C 但段落边界被 groove 模糊,ad-lib 层贯穿;70–95 BPM。
- **和声**:七九和弦、gospel 色彩、ii-V 链。**配器**:电钢/Rhodes、律动贝斯、细碎 hi-hat;**律动词比配器词重要**。**人声**:silky、melisma 少量点缀、falsetto、ad-lib 层。
- **词法**:句长**错落切分**、字要少——每行留长元音给转音,melisma 落点必须是开口元音;韵密度中等,slant 韵合法(口语感优先);语气=对话式、气声距离、现在进行时;细节=感官细节(温度/触感/光线)多于叙事细节。
- **弧线与 hook**:平缓微澜+ad-lib 推微高潮。
- **跑偏**:ballad 词配 R&B 伴奏(字太密、句太齐,没有 pocket);转音点放了闭口音;**中文特有的 mandopop 引力**——慢速+方正副歌+中文人声易塌成华语流行 ballad(尤其做档 2 可跟时主旋律 syllabic 更易触发),词法(错落 verse+pocket)、串、Exclude(防 `mandopop, pop ballad`)三层都要防。
- **Suno 要点**:`chinese r&b, smooth silky vocals, syncopated groove, laid-back, subtle vocal runs`。

## 6. 说唱 / hip-hop

- **身份**:flow、押韵技术本身是审美对象、punchline、authenticity。
- **曲式**:Verse(16 bar)+Hook 交替,无 Pre-Chorus;boom bap 85–95 / trap 书面 130–150 **体感减半**。
- **和声**:循环采样/极简,不承担叙事。**人声**:节奏咬字,flow 变化(双倍速/停顿)是技术展示位。
- **词法(通用默认反转最多)**:句长自由但严格对拍;押韵全曲风最高密度——多押/双押/内韵链,**4–8 bar 换韵是标配**(作用域=verse;hook 段韵脚随逐字重复固定不换;一韵到底在此=技术不足);verse 绝不重复,hook 重复;意象**高频换喻合法**(一步能懂放宽为两步,punchline 双关是审美);细节=专有名词/地名密度即可信度。
- **弧线与 hook**:循环型(Verse-Hook 交替,能量靠 flow 变化与 beat switch 推进);hook=重复短句段,verse 内不设 hook。
- **跑偏**:押韵密度不足像"念流行歌词";为多押牺牲语义(中文双押尤易生硬);flow 一个型到底。
- **Suno 要点**:`mandarin hip-hop, boom bap / trap, rhythmic flow, clear articulation`;书面 BPM 体感减半勿误设。

## 7. 中国风

- **身份**:五声旋律感、古典意象群、民族乐器、书面雅语域。
- **曲式**:流行 V-PC-C 骨架 + 国乐 intro/interlude;副歌常五声化。**BPM**:抒情型 60–80,中速叙事型 80–105。
- **和声**:五声调式为骨、流行和声托底。**配器**:古筝/笛/二胡/琵琶+流行节奏组。**人声**:清亮,戏腔限 Bridge/FC 一两处点缀。
- **词法**:**意象群铺陈路线**(方文山式:名词为画面单元——月/霜/檐/墨/茶);句长可对仗化(5–7 字骈句)或长短错落如词牌;押韵密、宽辙一韵到底常见;语域=书面雅,允许"天青色等烟雨"式主谓错位但必须一听即懂;姿态=常第三人称/时空距离感。
- **弧线与 hook**:爬升型或叙事推进型;hook=副歌题眼句(常为全曲最"雅"的一句),重复规范同流行。
- **跑偏**:**意象堆砌无叙事线**(最高发:每句都美,整首不知所云);生僻字唱不出/多音字倒字;伪文言语病;现代口语词混入破坏语域。
- **Suno 要点**:`chinese style pop, guzheng, dizi flute, erhu, pentatonic melody, cinematic`。

## 8. 电子 / 舞曲

- **身份**:build-drop 能量设计、hook 即全部、人声可作纹理、身体优先。
- **曲式**:intro-build-drop-break-build-drop(**没有 verse-chorus**;"副歌"=drop);house 120–128 / techno 125–135,四踩。
- **和声**:循环进行,情绪靠音色与 riser。**人声**:ethereal/processed 合法,人声=乐器,可切片(vocal chop)。
- **词法**:全曲风词量最少且**这是合法的**("细节>形容词"唯一弱化区);3–6 字短句;1–2 个 hook 短语循环到催眠;韵可有可无,元音质感>押韵;语气普遍化到近抽象;build 段词短促上行,drop 处词最少。
- **弧线与 hook**:循环型(多轮 build-drop);hook=1–2 个短语循环,drop 即"副歌"。
- **跑偏**:词写太多(叙事欲发作);drop 写成有完整句子的副歌。
- **Suno 要点**:`chinese electronic pop, synth pads, four-on-the-floor / downtempo, ethereal vocals`。

## 9. 爵士(vocal jazz / swing / ballad)★ 详版

### 身份要素(降序)
1. **swing 律动与 behind-the-beat 人声**——慵懒拖拍是第一身份;
2. **延伸和声色彩**(maj7/9/13、ii-V-I 链),且词的姿态要配得上和声的成人感;
3. **小编制对话感**——人声是乐手之一,词与乐器一句对一句(call & response);
4. **understatement**——情感浓度高、表达温度低;
5. **空间**——字密度全曲风最低档。

### 曲式
- **AABA 32 小节是母体**(A8+A8+B8+A8):三个 A 段**同旋律、不同词**(为同一旋律写三套递进的词才是真正的工作量);**没有流行意义的副歌**。B 段(bridge/release)是和声对比区(常上四度),歌词切视角/切时态/切句法至少占其一,**不碰 refrain**。ABAC(铺垫-铺垫-展开-结论,标题句落 C 段末尾,全曲只引爆一次)是另一大类。
- **引子 verse 传统**:正歌前 4–6 行 rubato 散文化口语引子(轻韵或无韵,speech-like),交代场景后进入 in tempo 正歌——流行结构里没有的、最能立刻"爵士化"的段落装置,也是"反前置 hook"的合法开场。
- **器乐 solo 占一个完整段落**(传统上一个 chorus),**词端必须留这个结构位**——不留位是"流行词配爵士编曲"跑偏的结构原因之一。情绪顶点常在 solo 后回归的最后一个 A 段。
- 传统收尾装置:**tag ending**(末句重复三次渐弱)、器乐 outro、半念白 croon 收。不默认哼唱。

### 律动/BPM · 和声 · 配器 · 人声
- swing 八分不均分;medium swing 110–140(俏皮/都市);70–110 为 medium-slow swing 过渡带(慵懒但有走路感,如 `lazy swing` ~100),按情绪靠档;**jazz ballad 55–70**,rubato 弹性大,鼓刷。
- ii-V-I、延伸音、半音下行——**和声本身在叙事,词不必满,留给和声说话**。
- 默认小编制:piano trio(钢琴+贝斯+鼓刷)+人声;muted trumpet/tenor sax 作 fills 与 solo。
- crooner 低吟/气声;scoop(滑入)与 fall-off(滑出)装饰;**同一乐句每遍唱法微变是身份,精确复制反而假**。音色参照系:白光—蔡琴的低音世故线(非周璇甜美线)。

### 词法(重灾区,最细)
- **句长:错落是身份,禁止规整对称**——规整对称句会诱导 AI 还原成流行旋律模具(本仓《长椅宽出一半》v1 实证:编曲全对、旋律仍流行)。长短句交错(如 8/4/9/5),模拟词牌长短句;一行内用标点制造气口,给乐器 response 留半句空间。**每句必须可拉伸**:句中停两拍仍语义完整;从句嵌套、一口气句判废。
- **字密度与词量预算**:全曲风最低档,ballad 每小节 2–4 字级别;**正歌总量 12–16 行为宜**(对齐 32 小节+慢板字少腔多;比同时长流行歌少 40% 以上的字),超预算先删行再删字;宁可少一句,不可挤一字。**每句只设 1 个重音焦点词**(Shirley Horn 美学:重读少数词,让其余滑走),放句末或倒数第二字,韵母开口度必须大(a/ai/an/ang/ao/ou)。
- **押韵:稀疏化**——隔句押或段末押即可,段间可换韵;用双声叠韵词与声母呼应(中文头韵)补音响粘性(Mercer 路线:韵少,头韵/元音呼应粘合)。韵要"聪明"(意料外但一听即服),是智力愉悦不是催泪装置;忌口水韵连排、忌一韵到底密押。
- **防倒字聚焦 refrain**:标题句关键词逐字检查声调走向(相邻字音高走向顺滑);其余句子允许常态匹配率(国语流行声调-旋律同向率本就只有约 38%、反向约 25%——Kirby 2023,听众靠语境纠偏)。**中文独有优势:滑音可顺四声滑**——去声字放乐句尾配 fall-off,阳平字放上行起句配 scoop,让弯音与读字互相成全。
- **闭口/窄元音(i、ü、in、ün)不做长音尾字**(慢板拖音 2–4 拍,闭口音又憋又散);口语虚词(了/吧/呢/就/还)是合法节拍垫——swing 的中文等价物;书面连接词(然而/亦/之)禁用。**对策"一字一顿"**:多用双声/叠韵/轻声制造粘连,安排"字少腔多"的短句配长旋律。
- **语气姿态**:都市成人、self-aware、微自嘲。**understatement 铁律:情绪名词(想念/悲伤/孤独/泪)全篇 ≤1 次**,每个情绪表达替换为一个事实、动作或物件,哭点留给听者完成。torch 姿态=第一人称对"你"低语(direct address),不控诉、不升华;Hart 技法=用小抱怨/小缺点写深爱,幽默是护住脆弱的壳;Porter 技法=清单式列举(A 段列具体旧物,末句 refrain 收拢——遗物题材量身定做)。
- **意象**:单一 conceit(一个核心比喻贯穿,与黄伟文单意象纵深同构);意象零浪漫电荷(器物白描并置于情感旁而不解释——Prévert 技法);**中文正统对接:悼亡/怀人走苏轼《江城子》路线**(生活片段白描、话家常语调、虚实切换、"用说不出代替说")。都市语域(夜/酒/雨/街灯/时钟);**乡土意象(田野/炊烟)不属于这个语域**。
- **swing 与 ballad 分写**:swing 词=俏皮、轻快动词、文字游戏、可密一点;ballad 词=每字千金、密度最低、姿态"看透仍温柔"、**忌哭诉**(哭诉是流行 ballad 的语法)。
- **中文语域锚点**:上海时代曲(1930-40s)是中文爵士的本土血统——古典韵律+现代白话、口语俏皮+都市意象+长短句,比直译英文标准曲更自然。

### 弧线与 hook
- **平缓微澜型**:靠密度、和声与 solo 起伏,不做流行式爬升;顶点=solo 后最后一个 A 段(或 tag 结尾)。
- **hook 机制:title 回归而非轰炸**——标题句固定在每个 A 段首句或末句(位置每次一致),全曲 3 次;前两次逐字或近逐字,**第三次允许换 1–2 个字制造终局刺点**(I Got Rhythm 式句式框架重复、填充变化)。B 段放弃 refrain。跟唱档 1 时此机制即核心可跟段:末次微变仍合法(变的是字,句式框架与旋律骨架不变,不破坏可哼性——singability 第三节);用户跟哼验收失败时首选收敛为三次全逐字再抽。
- 结尾允许**悬置**:停在未完成动作或客观事实上,不给安慰不给升华(When October Goes 路线)。

### 常见跑偏(按发生率)
1. **流行词+爵士编曲**(字太密、句对称、情感直白哭诉——三项全违,词层问题串层救不了);
2. 不给 solo 留结构位;
3. 意象乡土化;
4. swing 写成 uptempo pop 口号;
5. 把"慵懒"写成"慢"(ballad 的慢是弹性不是拖沓);
6. 中文特有:**mandopop 引力**——中文人声天然把模型拉向华语流行,词法+串+Exclude 三层都要防。

### Suno 要点
- 风格串锚词:`vocal jazz / jazz ballad, swing feel, behind-the-beat phrasing, brushed drums, upright bass, jazz piano with rich seventh chords, ii-V-I progressions`;人声:`smoky crooner, half-spoken croon, scoops and fall-offs, bluesy inflections`。串保持精简(15–30 词甜点,见 suno-spec §1)。
- **防"电梯爵士"平均化**(2026-07 工程调研,指南站口径):①**子流派必须点名**——裸写 jazz 会被平均成 smooth jazz("defaults to smooth jazz 90%");②**年代锚定**(1940s/1950s)+主奏乐器显式点名;③**场景词有效**(late-night club / candlelit bar——"room tone 先进 prompt");④swing 要显式写,否则 straight。人声按**三层法**写:质地(smoky/gravelly)+演唱(behind-the-beat croon/half-spoken)+制作(tape-warm analog / dry close-mic)——制作层最易漏。`AABA song form` 可入串但属**推断性锚词(待实测)**,行为不符即删并回写本节。
- Exclude 方向:防 `mandopop, pop ballad, polished clean vocals, modern pop production`(**不防 swing/upbeat——那是爵士的命根子**,本仓 v1 教训);`melodramatic` 与 restrained 类正向词叠加会压平演绎,默认不放、出哭腔再加。
- **曲式标签(AABA 的 Suno 实现)**:三个 A 段用**完全相同的标签文本(不编号)**——编号 `[Verse 1]/[Verse 2]` 的平台语义是"各段不同旋律",与 AABA"三 A 同旋律"相反;同旋律靠三重信号:同标签文本 + **三个 A 段同构的行长骨架**(为同一旋律写三套词是 AABA 词作的本职)+ 相同的段尾 refrain 行。B 段用 `[Bridge]`;引子 verse 用标准段落名+参数化(如 `[Verse: rubato, almost spoken, sparse piano only]`),不要发明非标准段落名。
- **对称句触发流行旋律为已证问题:词端解决优先于串端**(先把词写错落,再调串)。
- **后半流行漂移**(中文人声的 mandopop 引力随时长累积):当前缓解手段=词端错落 + Exclude 防流行族 + **后段的段落标签重申身份词**(hushed swing / behind the beat);仍漂移则从 solo 时点 Extend 重做后半再 Get Whole Song(注意 Extend 自身有风格漂移风险,需多抽)。(Suno 爵士工程专项调研两次挂起未完成;以上为本仓一手迭代经验,后续实测结论直接回写本节)

## 10. 蓝调

- **身份**:12-bar 循环、AAB 词式、蓝调音弯音、call & response、诉苦而不自怜的幽默。
- **曲式**:12 小节一轮 AAB——A 句陈述、A 句重复(微变合法,重复即修辞)、B 句反转/妙语;**唱句只占每 4 小节前半,后半是乐器 response(词端必须留白)**;solo 占整轮。**不写 verse-chorus**。收尾装置:末轮 B 句重复(tag)/乐队齐停(stop)/instrumental 渐弱。**轮次标签**:各轮统一用同文本 `[Verse: ...]` 不编号(编号语义=各段异旋律,与 12-bar 每轮同进行相反);跟唱目标时 B 句行文本固定。
- **律动**:shuffle/12-8;slow blues 50–70 / shuffle 120–140。**和声**:I-IV-V 属七、蓝调音阶。**人声**:粗粝、滑音弯音、即兴加花。
- **词法**:句长=口语一句话(8–14 字),句后必留白;**押韵不是重点,B 句的 twist/punchline 才是**;语气=第一人称诉苦+黑色幽默+夸张修辞;姿态=向酒馆众人说,不是向恋人低语;意象=器物/身体/在路上的白描(酒/车/雨/鞋/烟),都市底层语域,单域并置不解释。跟唱档 2 时 **B 句可全曲逐字固定**(recurring refrain 是蓝调传统合法形态),递进交给 A 句。
- **弧线与 hook**:循环咏叹型,不做爬升,靠每轮 B 句与 solo 推进;hook=每轮的 B 句反转位(句式重复、内容递进;档 2 跟唱目标时 B 句逐字固定、递进交给 A 句——见词法行)。
- **跑偏**:丢掉 AAB 写成流行段落;苦大仇深无幽默(自怜是大忌);词占满 12 小节没给吉他说话;中文特有:mandopop 引力同样适用(词法+串+Exclude 三层防,参照爵士节)。
- **Suno 要点**:`slow blues, 12-bar, shuffle, gritty vocals, electric guitar licks between phrases`。

## 11. bossa nova

- **身份**:①耳语式人声(绝不用力,第一身份);②batida 切分尼龙弦吉他;③saudade——甜的忧伤;④爵士级和声穿常服。
- **曲式**:AABA 或 verse-refrain 循环,流动不做大副歌;间奏留位一段(尼龙吉他或长笛,8 小节级)即可,不强制完整 solo chorus;55–75 BPM 体感,**平八不 swing**,人声浮在节奏上方微 lay back。
- **和声**:maj7/9/13、半音下行(Jobim 系)。**配器**:尼龙弦吉他为心脏、shaker、钢琴/长笛点缀。**人声**:气声近麦、几乎无 vibrato、**音域窄**(词端别写需要大跳的情绪词)。
- **词法**:简洁意象>密集叙事(海/阳光/街角);句长中短、随旋律流动、不求对称;韵轻、slant 合法;语气=**平静叙述强烈情感**(说思念像聊天气);词量少、段落可整段重复;语气词收尾(啊/呢类轻叹)可作装置。
- **弧线与 hook**:平缓微澜,全程克制不做爬升;hook=refrain 句循环回归,段落可整段重复。
- **跑偏**:唱得/写得太用力(一个 belting 全毁);词太苦太重(saudade 是甜的);写成慢速流行 ballad 配木吉他。
- **Suno 要点**:`bossa nova, nylon-string guitar, whisper-soft vocals, gentle syncopation, warm and bittersweet`。

## 12. city-pop

- **身份**:①都市夜景审美(driving/霓虹/海岸公路画面系统);②funk/disco 律动+爵士和声的"精致享乐"配方;③"富足又孤独"的情绪底色;④高光泽制作感。
- **曲式**:流行 V-PC-C 但 groove 全程不断;**器乐 riff 是第二 hook**。**律动**:boogie/disco 16 分 funk 切音、slap 贝斯,95–118 BPM。**和声**:maj7/9、IVmaj7→iii7→vi、明亮转调。**配器**:Rhodes、funk 吉他、合成 brass、萨克斯 solo。**人声**:干净轻盈、不用力、和声垫。
- **词法**:题材=夜驾/霓虹/末班车/夏夜海岸,享乐与怅惘**同框**;语气轻盈时髦、微苦回甘;句长中等偏整齐(流行骨架保留),韵中密;细节=都市消费社会语域的场景快照(出租车表跳字/便利店灯)。
- **弧线与 hook**:爬升型但顶点克制(groove 不为情绪让路);双 hook=人声副歌 + 器乐 riff。
- **跑偏**:写成土味怀旧金曲(city-pop 的乡愁是"对未曾拥有的旧时光的憧憬",不是怀旧);句子太重压垮 groove;意象域换成田园/校园就不像了;**mandopop 引力**——中文人声+副歌方正(做档 2 时)易漂成华语流行,靠 funk groove/爵士和声/都市意象顶住,Exclude 防 `mandopop` 方向。
- **Suno 要点**:`city pop, funk guitar, slap bass, rhodes piano, glossy 80s production, night drive mood`。

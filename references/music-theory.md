# 歌曲内容创作专业知识手册

> 供 AI 辅助中文歌曲创作使用。知识落在"能用文字表达、能指导创作决策"的层面。
> 术语中英对照,英文术语直接用于写 Suno 提示词。

## 板块 1:中文歌词写作

### 1.1 押韵体系:十三辙

**核心原则**:中文歌词押韵按"辙"(韵母归类)。选辙即选情绪底色——韵脚的开口度和共鸣位置直接决定歌的音色气质。开口大的辙适合放(副歌、豪迈),闭口细的辙适合收(主歌、私密)。(下表"音色气质"列为传统曲艺经验口径,方向与"宽韵洪亮、窄韵细弱"的通行说法一致。)

| 辙名 | 韵母 | 例字 | 音色气质 | 适合的情绪主题 |
|---|---|---|---|---|
| **发花辙** | a / ia / ua | 花、家、画、他 | 开口最大,明亮直白 | 热烈、直抒胸臆、乡土 |
| **江阳辙** | ang / iang / uang | 唱、香、光、方 | 洪亮开阔,鼻腔共鸣强 | 豪迈、辽阔、颂歌感 |
| **中东辙** | eng / ing / ong / iong / ueng | 风、梦、红、城 | 浑厚庄重,余音长 | 宏大、命运感、时代感 |
| **言前辙** | an / ian / uan / üan | 山、天、远、眼 | 半开口,绵长舒展 | **抒怀感叹第一选择**,思念、岁月(《传奇》韵脚:眼/颜/见/念/边;本仓库《正午的月亮》) |
| **人辰辙** | en / in / un / ün | 人、心、真、痕 | 收拢深沉,内敛 | 深情、隐忍、独白 |
| **怀来辙** | ai / uai | 海、来、爱、开 | 先开后合,有起伏感 | 感慨、释怀、告别 |
| **遥条辙** | ao / iao | 遥、笑、少、桥 | 温厚悠远 | 回忆、温情、乡愁(本仓库《归燕》) |
| **由求辙** | ou / iu | 走、酒、留、旧 | 绵长下沉,微微收口 | 忧愁、挽留、市井温柔(《成都》) |
| **梭波辙** | o / e / uo | 河、火、错、我 | 圆润含蓄 | 平静叙事、自省 |
| **灰堆辙** | ei / ui | 泪、醉、岁、微 | 低回婉转 | 哀伤、憔悴、酒后(《南山南》副歌韵脚:悲/堆/碑/飞) |
| **一七辙** | i / ü / -i / er | 你、雨、去、意 | 最细最尖,气若游丝 | 私密、细腻、青涩(《同桌的你》) |
| **姑苏辙** | u | 路、雾、孤、哭 | 最暗最沉,呜咽感 | 孤独、压抑、迷茫 |
| **乜斜辙** | ie / üe | 夜、月、别、雪 | 柔和清冷 | 离别、月夜、凄美 |

**操作要点**:
- **一韵到底**:情绪单一贯穿的歌(民谣叙事、小品式情歌)用,全曲统一感强;避免为凑韵硬填。**一韵到底只选宽韵**(常用字多:江阳、中东、言前、人辰、发花、遥条、怀来、梭波、一七);窄韵(乜斜、姑苏、灰堆、由求)字少易词穷,适合做局部用韵(一个 Bridge、一段主歌),取其独特音色。
- **通押尺度**:流行歌可接受前后鼻音通押(en/eng、in/ing,即人辰通中东);an/ang 通押仅在南方口音语感下成立,建议避免。
- **转韵时机**:主歌→副歌换辙是"升档"手法——主歌闭口辙(一七、人辰),副歌开口辙(江阳、发花、言前)。桥段再换一次韵,强化转折/抽离(《正午的月亮》Bridge 转怀来辙 -ai 即此用法)。押韵密度与换韵策略整体上是曲风参数,见 genre-profiles。
- **押韵密度**:隔句押(二、四句)最自然,适合叙事主歌;句句押推进感强,适合副歌。
- 韵脚落在乐句**重拍或长音**上最有效(快歌韵脚常落重拍短音,同样成立)。
- 避免"凑韵三俗":为押韵倒装、用生僻词、改变人称逻辑。

### 1.2 声调与旋律(倒字问题)

**核心原则**:中文四声与旋律走向冲突时会"倒字"。AI 生成无法逐音控旋律,防倒字要在**歌词层面**预防。

- 四声与旋律天然匹配:阴平宜平/高,阳平宜上行,上声宜低回,去声宜下行。
- **最易唱倒的位置**:①句尾长音 ②副歌最高音 ③hook 题眼词 ④歌名出现处。重点检查。
- 规避策略(按优先级):
  1. 韵脚和 hook 关键词优先选**阴平、阳平 + 大开口度元音**的字(a/ai/an/ang/ao 类:家、来、天、光),高音最稳;
  2. **上声(三声)字是头号危险**(我、你、好、想):低凹调 214 放句尾长音/最高音最易倒,放句中弱拍;
  3. 去声(51)起点高,放"高起下落"的旋律拱点反而很稳,仅在持续上行或高平长音处危险——不必一刀切避仄声;
  4. **同音歧义测试**:句子不带调念一遍,会听成别的词就换(星辰/新陈)。
- 分寸感:国语流行对倒字的容忍度显著高于粤语(听众靠语境自动纠偏),防倒字优先级排在"语感自然、不为协音牺牲词意"之后。

**进阶块:声调-旋律匹配的量化口径与操作规则(2026-07 调研)**(singability/lyrics 中"1.2 进阶块"即指本块;下列操作规则①②③对应"进阶块①②③")
- 数据口径:国语流行歌声调与旋律**同向率仅约 38%,反向(倒字)约 25%,斜向 37%**(Kirby 2023, CLS 58,国粤同旋律双语语料;粤语同向率 77%)——国语写词不可能也不必要全面协音,把协音资源集中在关键位置(hook/长音/最高音),其余交给语境纠偏。
- 操作规则:①每分句**声调最高的实词**放旋律最高音位;②虚词占拍短于实词(①②源自对陈小奇作品的词曲关系研究,《中国文艺评论》2019 第 8 期);③分节歌/多段同旋律时,**各段同位置的尾字用同声调字**——否则至少一段倒字(作曲教材口径;AI 同文本行同旋律机制下同理:重复段落的替换字保持声调一致)。**操作分层(可行性因辙宽而异)**:宽辙(言前/江阳/发花,候选字多)可全位对齐;窄辙(乜斜/姑苏等,候选池小、雅字声调不由挑)只对齐**关键位**(hook/最高音/句尾长音),不强求全位——否则句句押全位又要同声调,必生凑字,与"语感自然优先于协音"相悖。**逐字重复的副歌下此规则免费达成**(同文本必同声调)。
- 戏曲"依字行腔"四声口诀(可借鉴的精华):阴平可居最高音、两阴平相连前高后低;阳平配上行且不高于相邻阴平;上声先降后升或放低点;去声最灵活(降行/高起下落皆稳)。
- **叠词(AA/AABB)与衬词(啦/哟/嘿/哦)天然免协音压力**:声调同字重复、或无实义不怕唱倒,可垫节奏空隙与长音,同时降低倒字概率、强化记忆点——hook 与跟唱型歌曲的低风险填充材料。
- 救倒字:关键字声调难协时,戏曲手法是加前倚音先带出字调再入主音;Suno 端等价写法未经验证(如 `subtle grace notes`,推断性,小成本实测后再依赖)。

### 1.3 字数与乐句

- 4/4 拍中一句词通常对应 2 小节。**每句常见 5–11 字**:5–7 字紧凑上口(副歌),8–11 字舒展叙事(主歌),>12 字通常会抢拍(慢板 60–70 BPM 可容 12–14 字),AI 演唱易含糊。
- **副歌句子比主歌短**(流行/uptempo 惯例):主歌 8–11 字铺陈,副歌 4–8 字砸点。ballad 副歌可与主歌等长;爵士 AABA 无流行意义的副歌——见 genre-profiles。
- 相邻两句字数相等或只差 1–2 字,旋律倾向对称重复;行长错落则乐句错落——**对称还是错落是曲风选择**(流行/民谣求对称,爵士/说唱求错落),不是质量差异。
- 长短句交替 = 呼吸设计:"长长短"或"长短长短"稳妥。

### 1.4 歌词修辞

**核心原则:真实细节 > 形容词堆叠。**

- **意象域策略是曲风参数**(见 genre-profiles):民谣/爵士=单一意象域(全曲 1 个域,所有比喻从中取材);中国风=同域意象群铺陈;说唱=高频换喻合法。**无设计的混用才是散**。
- **隐喻的藏与露**(V-C 流行框架):主歌"藏"(只给意象),副歌"露"(点破情感)。黄金比例:主歌七分藏、副歌七分露。全藏晦涩、全露寡淡。(AABA 的藏露分布在 A 段递进与 B 段对照。)
  - 补充(本仓库验证):**含蓄 = 情绪藏着,不是句子看不懂**。每个意象单看必须一步能懂,深意藏在意象之间的关系里。
- **细节写作**:名词要有质感(旧车票、路灯、小板凳),动词要精确("攥"比"拿"疼)。写"她"不写"她很美",写"她把长发别到耳后"。
- **复沓**:同一句在段落间重复但改一个词("那时…"→"后来…"),民谣推进时间线的经典手法。
- **对仗/镜像**:上下句结构对称、语义相对("你说南方多雨 / 我说北方缺你"),副歌前两句用最出效果。
- **叙事视角**:第一人称对"你"倾诉是情歌默认;第三人称全知适合故事民谣;桥段切换视角是高级转折。

### 1.5 段落分工

> 本表按 V-C 流行曲式;AABA/12-bar/build-drop 的段落功能与力度分布见 genre-profiles 对应节。通用的只有功能思想:每段要给听众新东西。

| 段落 | 标记 | 写作要求 |
|---|---|---|
| 主歌 | `[Verse]` | 叙事、建景、给人物时间地点;信息密度高、情绪密度低;结尾一句为副歌搭桥 |
| 预副歌 | `[Pre-Chorus]` | 蓄力:句子变短、押韵变密、出现情绪升级词("直到/可是/原来");2–4 句 |
| 副歌 | `[Chorus]` | 核心句+记忆点;最高音区;语义脱离具体情节、上升到普遍情感,别人才能代入 |
| 桥段 | `[Bridge]` | 必须给**新信息**:换视角、跳时间、说破真相;旋律和韵脚都可换;忌重复副歌语义 |
| 尾声 | `[Outro]` | 回收——首尾呼应或题眼变奏;减字、留白 |

**Hook(题眼句)写法**(注意:位置与密度是**华语流行/ballad 工业规范**,其他曲风的 hook 机制见 genre-profiles):
- ≤9 字,收尾字选开口音+平声(通用:开口平声利于长音);
- 流行位置惯例:至少占住副歌第一句(先声夺人)或最后一句(收束);职业写法常**首尾都放**;一遍副歌内 ≥2 次,全曲 4–6 次;
- **机制(通用)**:AI 对相同文本行倾向给相似旋律,改一个字就可能换旋律——需要同旋律就给逐字相同文本。**重复密度是曲风参数**:流行=逐字轰炸;爵士=title 回归 3 次、末次可微变;民谣分节歌=钩子变奏;
- 检验(通用):听完一遍能否复述这一句——不能就重写。

### 1.6 多音字与 AI 演唱发音陷阱

**高危字清单**:了(le/liǎo)、还(hái/huán)、长(cháng/zhǎng)、重(chóng/zhòng)、得(de/dé/děi)、觉(jué/jiào)、行(xíng/háng)、曾(céng/zēng)、落(luò/lào/là)、弹(tán/dàn)、露(lù/lòu)、血(xuè/xiě)、薄(báo/bó)、切(qiē/qiè)、相(xiāng/xiàng)、数(shǔ/shù)、便(biàn/pián)、咯(gē/kǎ/lo,本仓库实测翻车)、着(zhe/zháo/zhuó)、只(zhī/zhǐ)、为(wéi/wèi)、朝(zhāo/cháo)、更(gēng/gèng)、倒(dǎo/dào)、地(de/dì)、背(bēi/bèi)、间(jiān/jiàn)、当(dāng/dàng)、散(sǎn/sàn)、尽(jǐn/jìn)、发(fā/fà)、正(zhēng/zhèng)。其中"为、只、着、朝、更"在情歌里频率极高。

规避策略:①能换同义词就换;②多音字放**双字词**里锁定读音("重逢"安全,单个"重"危险);③关键位置(hook、句尾长音)绝不放多音字;④社区实测补充:同音字整字替换("还→环",代价是字幕非原字)、括号注音法(正字后括号标同音字,不影响演唱)。
其他陷阱:生僻字跳读;儿化音不稳;叠词轻声("看看"第二字常被唱成重音);中英混排处易吞字。
(注:有 2026-05 教程称 v5.5 支持 `[Pronunciation: 字 = pīn yīn]` 标签,未见官方确认——先小成本实测再依赖。)

## 板块 2:曲式结构

### 2.1 主流曲式

**Verse-Chorus 型(中文流行默认)**:
```
Intro → V1 → (Pre) → Chorus → V2 → Pre → Chorus → Bridge/间奏 → Final Chorus(可升key) → Outro
```
- 典型小节数(4/4):Intro 4–8,Verse 8–16,Pre 4–8,Chorus 8–16,Bridge 4–8;
- 全曲:抒情歌 3:30–4:30,快歌 3:00–3:30;副歌(含重复)占全曲 40–50%。

**AABA 型(32 小节)**:A×2 → B(对比段)→ A 回归。复古、爵士、时代曲气质;hook 落在 A 段**首句或末句**(全曲同一位置重复)。

**民谣叙事型(分节歌)**:同一段旋律反复 3–5 遍,每遍换词推进故事;靠**歌词时间推进**撑全曲。每一节最后一句设计成"钩子变奏"——同一位置、词义递进(本仓库"暖得刚刚好→**还是**暖得刚刚好"即此手法)。

### 2.2 情绪弧线设计

> 通用原则只有一条:**能量曲线要被设计、要有对比**。弧线**形状**是曲风参数——爬升型(流行 ballad/摇滚 anthem,本节所述)、循环型(EDM build-drop/蓝调循环咏叹)、平缓微澜型(爵士/bossa,靠密度与和声微起伏,顶点常在 solo 后回归的最后一段——爵士 AABA 即最后一个 A 段)、克制反转型(顶点在最静处)。本节描述**爬升型**;其他形状查 genre-profiles。

- 起承转合:V1 起(最低动态)→ C1 承(七分力)→ Bridge 转 → Final Chorus 合(十分力)。
- **最高点放全曲 70–85% 处**(最后一遍副歌),太早后段泄气。
- **第一遍副歌不给满**:留 20–30% 余量。
- **大副歌前先收再放**:stripped-down(只留人声+一件乐器 1–2 句)再全奏——落差越大爆发越爽。标签写法:`[Bridge - stripped down, vocals and piano only]` → `[Final Chorus - full band, powerful]`。
- V2 比 V1 略加密度(多一件乐器),防"第二段主歌疲劳"。
- 克制型歌曲(不要爆发的)同样要有弧线,只是天花板压低:soft → swell → pull back,靠密度不靠音量。

### 2.3 前奏/间奏/尾奏

- **Intro**:建立调性、速度、音色身份。流媒体时代 5–15 秒;`short intro` 可压前奏。
- **Interlude**:第二遍副歌后 4–8 小节喘息;V-C 流行曲式内与 Bridge 功能二选一,别都放满(爵士例外:solo 是独立结构位,与 B 段/bridge 并存;蓝调的 solo 轮与乐句间 response 也是独立结构位——12-bar 本无 bridge)。也可用于**时间转场**(换配器=换时代,本仓库《归燕》)。
- **Outro**:fade out(余韵型)或 cold end(决绝型);民谣常回收前奏动机形成闭环。

## 板块 3:节奏与律动

### 3.1 拍号的情绪属性

| 拍号 | 听感 | 适用 | 提示词 |
|---|---|---|---|
| 4/4 | 方正、行进、万能 | 90% 流行歌 | 不用写 |
| 3/4 | 旋转、圆舞曲、复古优雅 | 怀旧深情慢歌 | `waltz, 3/4 time` |
| 6/8 | 摇篮般摆荡、海浪感 | 深情抒情、安眠曲、哄睡感 | `6/8 time, swaying feel` |
| 12/8 | 6/8 加宽,慢摇滚三连音慢板 | soul ballad 深情爆发型 | `12/8 slow blues feel` |

⚠️ **关键事实(2026 实测)**:Suno 的**拍号数字本身不影响生成**(Studio 里的 time signature 只作用于编辑网格)。想要三拍/摆荡感,靠的是 `waltz`、`swaying lullaby feel`、`slow blues shuffle` 这类**风格词**驱动——表中提示词有效的部分是词,不是数字。华语流行纯 3/4 少见,想要圆舞曲感直接写 `waltz` 即可。

### 3.2 BPM × 情绪映射

| BPM | 情绪/曲风 |
|---|---|
| 60–75 | 深情慢板(苦情歌、钢琴抒情) |
| 76–90 | 抒情民谣/温暖叙事 |
| 90–108 | 中速流行、治愈系(《成都》体感约 90,检测 182 双倍) |
| 108–120 | 轻快流行、甜歌 |
| 120–130 | 舞曲(four-on-the-floor) |
| 100–140 | 摇滚(朋克多在 160+) |

- 提示词写法:**数值 + 速度形容词双保险**(`slow ballad around 70 BPM`)——数值是近似引导,不是节拍锁。
- ⚠️ **half-time 流派陷阱**:trap/现代 hip-hop 书面 130–170 BPM 但鼓按半速击点,**体感 65–85**;"BPM=情绪快慢"对这类流派失效,写 `140 BPM trap` 得到的是慢体感。
- 测参考曲 BPM 时注意检测工具的**双倍检测**(报 160+ 的慢歌先除以 2)。

### 3.3 律动术语(提示词直接可用)

- **straight**:平均八分,工整干净(流行默认)
- **swing / shuffle**:摆动三连音化,慵懒复古爵士感
- **syncopation**:重音落弱拍,"勾人"推力(funk/R&B)
- **behind the beat / laid-back**:人声微拖后于节拍,松弛老练——自由律动体裁(民谣/爵士/bossa/R&B)去机器感的关键词;网格律动体裁(电子/说唱/朋克)不适用,反而伤身份;反义 pushing(赶拍,朋克的合法能量来源)
- **half-time**:体感减半,瞬间变"沉、宽"(桥段变化用)
- **four-on-the-floor**:底鼓每拍踩,舞曲脉搏
- **tight pocket / loose groove**:律动咬合紧/松

## 板块 4:调性与和声

### 4.1 调式情绪

- **大调**:明亮、肯定、温暖(治愈、甜歌)
- **自然小调**:忧郁、内省、深情(中文抒情半壁江山)
- **Dorian**:忧而不绝望,都市夜色、R&B
- **五声音阶/民族调式**:宫调式明朗古雅,羽调式婉转苍凉——中国风身份证。`Chinese pentatonic scale, guzheng`
- 常用调:C、G、F 大调及关系小调 Am、Em、Dm(吉他钢琴友好)。给 AI 写 `in a minor key` / `major key` 控底色即可。

### 4.2 经典和声进行

| 进行 | 级数(C 大调) | 听感 | 典型应用 |
|---|---|---|---|
| **4536251(万能进行)** | F–G–Em–Am–Dm–G–C | 层层下行叹息,缠绵忧伤,"中式抒情"默认味 | 华语苦情歌/ballad 绝对主力 |
| **卡农进行** | C–G–Am–Em–F–C–F–G | 庄重循环下行,怀旧、青春、岁月 | 毕业歌、青春纪念 |
| **1645** | C–Am–F–G | 复古甜美(50s),初恋感 | 老派情歌、校园民谣 |
| **6415** | Am–F–C–G | 感伤流行进行,忧郁有推进力 | 现代流行/民谣副歌循环 |
| **1564** | C–G–Am–F | 国际万能循环,开阔直给 | 体育馆合唱型副歌 |

- 主歌小调色彩 + 副歌大调色彩 = "隐忍→释放"的和声写法。
- 4536251 的"叹息感"机理:4→5 先上行一步,随后 3–6–2–5–1 进入**下行五度循环(圈进行)**,缠绵感来自这段连锁下行。
- Suno 对级数理解有限,写 `emotional Chinese pop ballad chord progression` 这类风格描述更可靠;真想控和声,实际路径是 **Studio 上传自己弹的参考音频**让模型跟随(v5.5),不是文字。

### 4.3 转调用法

- **最后副歌升 key**(升半音/全音):情绪硬拉一档,大情歌终极爆发。`key change up for the final chorus`。用一次,且前面必须先"收"过。
- 平行大小调互换:主歌 Am、副歌 C,阴转晴。

## 板块 5:编曲与配器

### 5.1 配器角色表(提示词对照)

| 乐器 | 英文 | 角色与情绪 |
|---|---|---|
| 木吉他 | acoustic guitar(fingerpicked/strummed) | 亲密真诚,民谣身份证;指弹=私语,扫弦=行进 |
| 钢琴 | piano | 叙事、干净的忧伤;ballad 骨架 |
| 弦乐 | strings | 升华、电影感;副歌加入=镀金,慎在主歌用满 |
| 合成器铺底 | ambient synth pad | 氛围填充,不抢戏 |
| 鼓组 | brushed drums(鼓刷)/soft drums | 推动力;鼓刷=温柔复古 |
| 贝斯 | upright bass / warm bass | 温度和律动地基 |
| 口哨 | whistling | 轻松洒脱街头感 |
| 口琴 | harmonica | 流浪、公路、孤独浪漫 |
| 环境音 | ambient sounds(rain, vinyl crackle, birdsong) | 场景锚点,intro/outro 点睛 |
| 民乐 | guzheng/erhu/dizi/pipa | 中国风;二胡=悲,笛=远,古筝=雅 |

### 5.2 编曲密度与动态(加减法;密度公式为 V-C 流行/ballad 惯例,其他曲式的密度设计按 genre-profiles)

- 流行/ballad 密度公式:**V1 用 1–2 件 → Pre 加 1 件 → Chorus 全奏 → V2 比 V1 多一件 → Bridge 减法 → Final Chorus 最大**。(爵士小编制全程稀疏、蓝调 12 小节循环、电子走 build-drop,均不走此表。)
- **build-up**:进副歌前鼓加花/军鼓滚奏/riser 铺垫;**drop**:满编爆点;**stripped-down**:突然只剩人声+一件乐器——流行/ballad 常用且性价比高的动态武器。
- 段落对比靠加减法,不靠所有乐器一起变大声。
- 标签写法:`[Verse - acoustic guitar only]`、`[Chorus - full band with strings]`、`[Bridge - stripped down]`。

### 5.3 中文民谣的标志性配器语言

- **校园民谣**(90 年代,《同桌的你》系):木吉他分解为绝对主角 + 口琴 + 简单和声,鼓弱化。`Chinese campus folk, fingerpicked acoustic guitar, harmonica, nostalgic`
- **城市民谣**(《成都》系):木吉他 + 钢琴/弦乐 + 鼓刷 + 温暖贝斯,带都市倦意。`Chinese city folk ballad, acoustic guitar, soft strings, brushed drums, warm and melancholic`
- **新民谣**:手风琴、曼陀林、弦乐四重奏;人声偏生涩质朴。

## 板块 6:人声与演唱表达

### 6.1 三层描述法:声部 + 音色 + 处理

**声部**:male bass / **baritone(男中——中文民谣叙事感的黄金声部)** / tenor;female alto / mezzo / soprano。

**发声方式**:chest voice(胸声,扎实)、falsetto(假声,飘、脆弱)、mixed voice(混声)、**breathy voice(气声——中文抒情歌标志性质感)**。

**音色形容词**:warm、husky、smoky、breathy/airy、raspy/gravelly、clear、sweet、mellow、deep、bright、soft、powerful、tender、youthful、mature、emotive。
组合示例:`warm husky male baritone vocals`。

### 6.2 演唱处理术语

- **rubato**:自由节拍,民谣开头结尾常用
- **ad-lib**:即兴加花,`emotional ad-libs in outro`
- **melisma / vocal run**:一字多音的转音(melisma 是总称,vocal run 特指快速音阶型经过句、偏炫技);中文歌宜少量点缀,多则油
- **falsetto flip**:句尾翻假声,脆弱感拉满
- **spoken word**:念白段,独白桥段利器
- **whisper**:耳语,极端私密
- **力度设计**(V-C 流行弧线的默认;力度天花板与分布按 genre-profiles):soft/restrained → building → belting → powerful climax;主歌 restrained,副歌 open,final chorus belting(克制型歌全程 restrained,用 swell/pull back 做微起伏;爵士/bossa 全程低天花板)

### 6.3 "真人感"的四个微观维度(全部可写进提示词)

1. **呼吸**:`audible breaths, intimate vocals`
2. **微观时值偏移**:`slightly behind the beat, relaxed phrasing`
3. **力度变化**:`dynamic vocals, from whisper to belt`
4. **咬字轻重**:`soft articulation`(亲密)/ `crisp enunciation`(宣告)

组合示例(民谣男声):`intimate male baritone, breathy and warm, audible breaths, slightly behind the beat, soft articulation, like singing to one person`

## 板块 7:混音与整体质感(简要)

- **干/湿**:dry=贴脸真实(`dry intimate vocals`);wet=空旷梦幻(`lush reverb, spacious`)。民谣宜偏干。
- **远/近**:`close-miked, intimate` / `roomy, distant`
- **宽/窄**:`wide stereo image` / `narrow, mono-like, vintage`
- **质感三档**:`lo-fi, tape saturation, vinyl crackle`(怀旧卧室感)/ `live recording feel, room ambience`(真诚现场)/ `polished studio production`(主流默认)
- 抒情歌保动态:`dynamic mix, not over-compressed`;LUFS 数值 Suno 不响应,不写进提示词。
- **发布级后期与响度标准**(交付层,不是提示词层):见 production-advanced.md 的后期制作链——分轨 → 修音 → 混音 → 母带,交付目标 **-14 LUFS / True Peak ≤ -1 dBTP**(Apple Music -16 LUFS);超响母带会被平台归一化拉回,只损失动态。

## 附:完整提示词组装顺序(速查)

```
曲风+地域标签 → 拍号/BPM → 调性色彩 → 配器清单 → 人声(声部+音色+处理) → 律动词 → 质感标签
```

